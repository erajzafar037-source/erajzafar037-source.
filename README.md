2. Enterprise AI RAG System — Industrial Project
View repository →

A production-oriented RAG reference implementation that demonstrates document ingestion, semantic retrieval, API serving, evaluation, and operational visibility.
- PDF ingestion with page-aware chunking and Sentence Transformers embeddings.
- FAISS semantic search with a NumPy similarity-search fallback.
- FastAPI endpoints for document upload, grounded question answering, and streamed responses.
- Redis response caching, Prometheus metrics, and an offline evaluation harness.
- Docker Compose and Kubernetes manifests with health probes and horizontal pod autoscaling configuration.
Stack: Python · FastAPI · Sentence Transformers · FAISS · OpenAI API · Redis · Prometheus · Docker · Kubernetes

Engineering note: the current vector index is in-memory and the repository documents security and persistence work still needed before multi-tenant or sensitive-data use.
